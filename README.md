# Soul Good Boxathon — Timer Dashboard

A self-contained, single-file timer dashboard for running multi-station boxing/circuit
events ("Boxathon") at Soul Good. No build step, no server — just open `index.html`.

## What it does
- Define a shared **lap program** (warm-up, rounds, rest, cool-down) — each lap optional timed.
- Add multiple named **station timers** that all progress through the same laps.
- Timed laps **count down**, beep, **announce by voice**, and **auto-advance**.
- **Start / Next Lap (All)** drives every station together.
- Assign a **keyboard key** to each timer (1, 2, 3…) to advance it hands-free.
- **Save / load / export / import** workouts.
- **Wall display** mode — giant timers for the room (full-screen; press Esc to exit).
- Everything persists in the browser (localStorage).

## Use it
Open **index.html** in Chrome, Edge, or Safari. (Voice requires a real browser tab.)

Built for Soul Good Boxing — brand: Ink / Bone / Fog / Ember.
